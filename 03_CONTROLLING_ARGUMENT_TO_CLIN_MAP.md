# Controlling Argument-to-CLIN Map

## Function

This is the finite proposition map. It links each argument the case is willing to make to the canonical record and identifies its evidential role.

Evidence classes:
- **CC** contemporaneous clinician
- **CP** contemporaneous patient
- **LC** later clinician
- **RP** retrospective patient
- **POD** Podiatry
- **GEN** genetics
- **NI** negative / record-wide inference
- **EXP** expert-dependent

**CLIN:** `000020–000025`; `000068–000073`; `000102–000105`; `000192–000198`; `000851–000884`.
