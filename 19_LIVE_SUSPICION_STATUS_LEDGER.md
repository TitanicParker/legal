# 19 — Live Suspicion Status Ledger

## Purpose

This file answers one question at all times:

> **What is the present status of each material limb of the governing suspicion?**

The repository is governed by the suspicion, but not every limb has the same evidential status. This ledger prevents two opposite errors:

- treating a weak or unresolved limb as established merely because it is serious; and
- allowing a weaker unresolved limb to obscure a stronger centre that is already supportable.

---

# Status scale

- **ESTABLISHED DOCUMENTARY PREDICATE** — source record directly supports the factual predicate.
- **STRONG REASONABLE INFERENCE** — cumulative evidence presently supports the inference.
- **LIVE SUSPICION** — materially supported but dependent on unresolved evidence.
- **EXPERT-DEPENDENT** — factual predicates exist but breach/medical significance requires expert opinion.
- **FORENSICALLY UNRESOLVED** — decisive evidence is version/audit/authorship/provenance material not yet obtained.
- **WEAKENED / NARROWED** — later evidence has materially reduced the scope of the limb.
- **DEFEATED** — evidence no longer permits responsible reliance on the limb.
